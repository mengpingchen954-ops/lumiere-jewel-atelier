# 小光珠宝工坊 / Lumière Atelier

原创的 Three.js 浏览器 3D 珠宝制作模拟。领取材料 → 实际局部打磨 → 拖放镶嵌 → 节奏收爪 → 局部抛光 → 命名、收藏与交付。两份制作委托、一份保留原件的修理委托，之后可继续自由创作。

## 线上版本与发布状态

发布目标为 GitHub Pages，网页 https://mengpingchen954-ops.github.io/lumiere-jewel-atelier/ ，源码 https://github.com/mengpingchen954-ops/lumiere-jewel-atelier 。已通过 GitHub Actions 构建发布与 74 项匿名浏览器交互检查，详见 docs/GITHUB-VALIDATION.md。后方镜头的墙面遮挡已修复，转到背面时背景会自动剖开。旧 Netlify 站点保留，不再作为发布目标。旧存档迁移：在旧页面帮助里下载备份，再在新页面帮助里导入。

## 启动

在此目录执行 `npm install`（当前工作区已提供父级依赖），然后 `npm run dev`，打开 http://127.0.0.1:5190 。也可双击 start-game.cmd。生产构建 `npm run build`；生产预览 `npm run preview`，地址 http://127.0.0.1:4190 。需要 Node.js 20.19+ / 22.12+。

## 操作

- 左键使用选中的工具；右键旋转；滚轮缩放；正面/背面/俯视与缩放按钮在画面底部。
- 精细锉刀：按住左键沿金色点来回拖动，直到每段磨平。不会挂机增长。
- 镶石镊子：打磨完成后，从右侧小碟把宝石拖到戒指顶部镶口，提示对齐后松手。
- 收爪钳：节奏指针进入绿色区域后，逐个点击镶爪。转到背面收紧后面两爪。
- 羊毛抛光轮：按住左键擦过青色点。只有先打磨好的区段才会抛亮。
- 放大镜：修理前点击三处磨损、松动的右前镶爪，诊断后对应处理。
- 刻花笔：完成任意订单后，材料铺花 80 币购买。选择花/叶/星，点击四个戒肩连接位来装饰。
- 1–6 工具快捷键；V 镜头；Esc 取消工具；Ctrl+Z 撤销、Ctrl+Y / Ctrl+Shift+Z 重做。
- 未满足订单条件时，检视界面逐项列出缺项，返回继续编辑。

## 作品、资源与经营

2 种戒托 × 3 种金属 × 3 种宝石颜色 × 3 种切形，4 个连接位 × 3 种装饰。领料时扣一次库存；退回/切换可返还未交付原料；交付有唯一记录，不会二次收款。免费练习包在银料或蓝晶耗尽时可领取，自由成品也可寄售获得收入，即使花光委托报酬也能继续购买工具，避免资源死局。

工坊、作品结构、加工区段、修理诊断、名称、订单、库存、资金、解锁统一存 localStorage。保存失败明确提示；损坏存档保留原数据并阻止自动覆盖。帮助页面可导出/恢复 JSON 备份。不要清理浏览器站点数据，或先下载备份。无账户、无云存档。

成品可收藏、按真实三维结构重开、返回原草稿、另作新副本。PNG 照片由当前 WebGL 画面生成，移除工具指示。作品匣缩略图同样来自实际渲染。

## 验证与发布

`npm test` 验证加工条件、局部效果、扣料/退款、三订单与重复结算、作品副本和存储失败；`npm run test:browser` 使用安装的 Chrome / Playwright 实际发出鼠标拖动、定时点击和键盘操作。无需通过调试接口修改游戏状态。测试设备、GPU、性能、截图和结果保存在 artifacts/test-report.json。默认浏览器测试访问开发端口；可设 GAME_URL 测生产预览或公开站点。公共站点测试使用无 cookies 的全新 context。

`npm run deploy` 使用 Git Credential Manager 的现有 GitHub 登录，上传当前游戏源码、必要资源与工作流到独立公开仓库。GitHub Actions 执行 npm ci、状态测试、生产构建，然后发布 dist 到 GitHub Pages。Vite 使用相对资源路径，兼容仓库子目录部署。绑定记录在 docs/github-pages.json。仓库不含凭据、存档或测试产物。

建议桌面 Chrome 与鼠标，移动端提供响应式布局和触控基础输入，但本轮完整流程验收针对桌面鼠标。首次加载需要 WebGL2。下一轮优先：更细的二维表面网格、更多珠宝类别/工艺、宝石折射与工作台细节提升。
